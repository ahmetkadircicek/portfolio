# Anayasa
Bu repo Ahmet'in tasarım zevkini temsil eder. Tasarım, UI, ekran, renk, tipografi veya mobil arayüz işi geldiğinde:
1. Önce `taste/profile.md` dosyasını oku.
2. `skills/ahmet-designer/SKILL.md` akışını uygula.
3. Çıktıyı sunmadan önce zevk profiline uygunluğunu kontrol et.

Kesin kurallar
- `taste/profile.md` ve bu dosyayı sadece Ahmet onayıyla değiştir.
- Ahmet "çirkin" derse görseli sil, sadece hash'ini `dataset/rejected.txt` içine yaz.
- Ahmet adına hiçbir yere yayın yapma, önce onay al.
- API anahtarı veya gizli bilgi commit etme.
